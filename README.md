# CineVault Watchlist 🎞️

A film watchlist for movie lovers. Add the movies you want to see, mark the ones you have already watched, rate them, and filter by title, status or genre.

Built by [CineVault8](https://cinevault8.blogspot.com/)

## Features

- Add films with title, year, genre and an optional rating (1 to 10)
- Mark films as watched or unwatched
- Search by title and filter by status or genre
- Stats: total films, watched, to watch and average rating
- Duplicate detection (same title and year)
- No installation, build step or server required

## Demo

Open `index.html` in your browser to try it locally, or enable GitHub Pages (see below) to get a live link.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern browser.

## Enable GitHub Pages (Optional)

1. Go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute or two, your demo will be available at `https://your-username.github.io/cinevault-watchlist/`.

## Limitations

This is a demo. Your watchlist is stored in the browser's local storage, so it is not synced between devices or users. A production app would need a backend server and a database.
